# Patrick Jane

Patrick Jane is a local, own-AI assistant project built in this repo so you can test it without any external AI API.

It includes:
- local command engine
- app launching logic
- Spotify launch behavior
- Roblox concept generator
- YouTube clip highlight planner
- futuristic classic dashboard UI

## Run locally

From the project root:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python server.py
```

Then open:

```text
http://localhost:8000
```

## Commands you can try

- Patrick, wake up Patrick
- Patrick, open Spotify
- Patrick, play music
- Patrick, create a Roblox anime fighting game
- Patrick, analyze this YouTube video: https://www.youtube.com/watch?v=dQw4w9WgXcQ

## Notes

This version does not use external AI APIs. It is a local, own-AI assistant built directly in the repository so you can run, test, and expand it easily.

The assistant is rule-based and designed to be easy to extend with your own logic or future features.
